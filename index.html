This page reads and writes the Current List Items and Retired List Items worksheets of your to-do workbook through Microsoft Graph. Columns: Date, Priority (M/S/C/W), List Item, Tag.

One-time setup: you can reuse the app registration from your Food Safety dashboard. In the Entra admin center, open it, add this page’s URL (shown below) as an additional Single-page application redirect URI, and keep delegated Files.ReadWrite. No client secret is used.
  1. Host this HTML on an HTTPS website (same place as your other dashboards).
  2. Add the redirect URI below to the app registration.
  3. In OneDrive, create a sharing link for the to-do workbook (Share → Copy link, with edit permission).
